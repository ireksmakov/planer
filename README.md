# Планер

Редакционный планировщик задач на день, неделю и месяц. React + TypeScript + Vite + Tailwind CSS + date-fns, без сервера.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173).

## Проверка и сборка

```bash
npm run typecheck
npm run build
npm run preview
```

Задачи автоматически сохраняются в `localStorage` браузера (`planer.editorial.tasks.v1`); в приватном режиме или при блокировке хранилища они сохраняются лишь до закрытия вкладки. День, неделя и месяц используют одни и те же данные. Удаление задачи выполняется сразу.

Fraunces загружается из Google Fonts, Satoshi — из Fontshare (в Google Fonts этого семейства нет). Поскольку обе гарнитуры не содержат кириллицу, для русского текста подключены совместимые шрифты Google Fonts Cormorant Garamond (заголовки) и Manrope (интерфейс). Это обеспечивает корректную редакционную типографику на русском языке без запрещённых шрифтов. При отсутствии сети используются Georgia и Helvetica Neue.

## Оформление

Новый исламский визуальный стиль: изумрудный и золотой, геометрический орнамент, арочные детали, Amiri для арабского текста, Manrope и Cormorant Garamond. Задачи остаются в localStorage.

## Перенос просроченных задач

На странице «Сегодня» показаны все невыполненные задачи с датой раньше текущей (время задачи не влияет на просрочку). Для каждой есть кнопка «Перенести»: можно сразу выбрать сегодня, завтра или указать другую дату в календаре. После переноса задача меняет только дату и автоматически появляется в соответствующем дне, неделе и месяце. Название, приоритет, категория, время, ID и данные в localStorage сохраняются. Выполненные задачи не считаются просроченными. При просмотре прошлых дней перенос также доступен внутри задачи.

## Цветовые статусы и список просроченных задач

На странице «Сегодня» просроченные задачи показаны в компактном красно-терракотовом градиентном блоке с кнопкой «Развернуть список задач»; при открытии доступны прежние действия переноса, изменения и удаления. Текущие и будущие невыполненные задачи выделяются зелёным статусом с мягко пульсирующей точкой (анимация отключается при prefers-reduced-motion). Сами данные задач и ключ localStorage не меняются.

## Задачи на сегодня

Задачи выбранного сегодняшнего дня отображаются в отдельном округлом зелёном градиентном блоке со статусом «В процессе», счётчиками задач и общим списком. Если все задачи выполнены, статус меняется на «Всё выполнено». Когда дата задачи становится прошедшей и задача остаётся невыполненной, она попадает в красный блок просроченных задач (на вкладке «Сегодня»). Формы, задачи и localStorage остались прежними.
